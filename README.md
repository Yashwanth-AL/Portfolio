# Personal Portfolio Website# Here are your Instructions


A modern, responsive personal portfolio website built with React.js and TailwindCSS. This portfolio showcases my skills, projects, achievements, and professional experience in an elegant and interactive way.

## 🌟 Features

- **Responsive Design**: Fully responsive layout that looks great on all devices
- **Dark Mode**: Seamless dark/light mode switching for comfortable viewing
- **Interactive UI**: Smooth animations and transitions using Framer Motion
- **Modern Stack**: Built with React.js and TailwindCSS for modern web standards
- **Component-Based**: Modular architecture with reusable components

## 🚀 Sections

- **Hero**: Eye-catching introduction with social media links
- **Education**: Academic background and qualifications
- **Experience**: Professional experience and work history
- **Projects**: Showcase of notable projects with live demos and source code
- **Skills**: Technical skills and competencies
- **Achievements**: Notable certifications and accomplishments
- **Contact**: Easy ways to get in touch

## 🛠️ Technologies Used

- **Frontend Framework**: React.js
- **Styling**: TailwindCSS
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Package Manager**: npm
- **Version Control**: Git

## 💻 Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/Yashwanth-AL/Portfolio.git
   ```

2. Navigate to the frontend directory:
   ```bash
   cd Portfolio/frontend
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm start
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser

## 📝 Project Structure

```
frontend/
├── public/              # Public assets
├── src/
│   ├── components/     # React components
│   ├── contexts/       # Context providers
│   ├── data/          # Mock data and constants
│   ├── hooks/         # Custom React hooks
│   ├── lib/           # Utility functions
│   ├── App.js         # Root component
│   └── index.js       # Entry point
└── package.json       # Project dependencies
```

## 🎨 Customization

1. **Content**: Update the data in `src/data/mock.js` with your information
2. **Styling**: Modify TailwindCSS classes in components
3. **Theme**: Adjust colors in `tailwind.config.js`
4. **Components**: Add or modify components in `src/components`
